# 🐐 Meu Painel Goat - Dashboard Financeiro

Painel financeiro pessoal desenvolvido para gestão de despesas e controle de saldo em tempo real, construído com tecnologias web modernas para garantir alta performance, portabilidade e persistência segura em nuvem.

## 🚀 Tecnologias Utilizadas
* **React + Vite:** Interface de usuário dinâmica, rápida e reativa.
* **Tailwind CSS:** Estilização moderna com design system limpo e responsivo (tema escuro).
* **Firebase Realtime Database:** Armazenamento em nuvem em tempo real para garantir que nenhum dado seja perdido.
* **Vercel:** Hospedagem web contínua e gratuita.

## 💡 Funcionalidades
* Registo e controlo de transações financeiras.
* Sincronização automática na nuvem (os dados ficam salvos independentemente do dispositivo ou navegador).
* Interface limpa, otimizada para uso diário pessoal.
